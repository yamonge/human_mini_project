# Curtain Call — Frontend

`human_mini_project`의 React 클라이언트입니다. 전체 설명·백엔드 실행 방법은 [저장소 루트 README](../../README.md)를 참고하세요.

## 실행

```bash
npm install
npm start
```

백엔드(`http://localhost:8111`)가 먼저 실행되어 있어야 합니다.

## 스크립트

| 명령 | 설명 |
|------|------|
| `npm start` | 개발 서버 (포트 3000) |
| `npm run build` | 프로덕션 빌드 |
| `npm test` | 테스트 실행 |
